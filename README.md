# Описание

Данный проект представляет собой консольное приложение для учета животных и инвентаря Московского зоопарка. В основе архитектуры лежат принципы ООП и SOLID, что обеспечивает гибкость, расширяемость и тестируемость кода.

## Основные классы

* Animal (абстрактный класс) — базовый класс для всех животных.

* Herbo, Predator — классы, разделяющие животных на травоядных и хищников.

* Monkey, Rabbit, Tiger, Wolf — конкретные виды животных.

* Thing (абстрактный класс) — базовый класс для инвентаря.

* Table, Computer — примеры предметов инвентаря.

* VeterinaryClinic — проверяет здоровье животных перед добавлением в зоопарк.

* ZooService — управляет животными и инвентарем.

* AppConfig — конфигурация Spring-контейнера.

## Функциональность

* Добавление животных в зоопарк (с проверкой здоровья).

* Добавление инвентаря.

* Подсчет общего потребления пищи животными.

* Получение списка животных, подходящих для контактного зоопарка.

* Изменение уровня доброты травоядных животных.

* Вывод характеристик животных.

* Вывод списка инвентаря.

## Принципы SOLID

* S (Single Responsibility): разделены классы для работы с животными (ZooService), инвентарем (Thing) и проверкой здоровья (VeterinaryClinic).

* O (Open/Closed): можно легко добавить новых животных и предметы без изменения существующего кода.

* L (Liskov Substitution): любые подклассы (Monkey, Rabbit, Tiger, Wolf) могут использоваться вместо Animal без проблем.

* I (Interface Segregation): животные реализуют IAlive, инвентарь — IInventory, не перегружая классы ненужными методами.

* D (Dependency Inversion): используется внедрение зависимостей через Spring, ZooService не создает VeterinaryClinic самостоятельно.

## Объектно-ориентированное программирование (ООП)

* Инкапсуляция: данные (name, foodConsumption, levelKidness, number) скрыты и управляются через геттеры/сеттеры.

* Наследование: классы Herbo и Predator унаследованы от Animal, а Thing служит базой для инвентаря.

* Полиморфизм: общий интерфейс IAlive позволяет работать с разными животными единообразно.

* Абстракция: Animal, Herbo и Thing — абстрактные классы, задающие базовые характеристики объектов.

# Запуск проекта

1. Клонировать репозиторий

2. Убедиться, что у вас установлены Java 21 и Maven

3. Прописать `mvn clean install`
